🎯 Features
Two-player Stone-paper-scissor
Detects the winner
Detects winning patterns

Responsive layout
🛠️ Technologies Used
HTML
CSS
JavaScript
How to Play
Open the game in your browse
choose from stone, paper or scissors starts the game.
one of them will be choosen by computer randomly

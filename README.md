🪨📄✂️ Stone Paper Scissor

A simple Stone Paper Scissor game built using HTML, CSS, and JavaScript.

🎯 Features

🎮 Play Stone Paper Scissor against the computer

🏆 Detects the winner

🔄 Detects all winning patterns

📱 Responsive layout

🛠️ Technologies Used

HTML

CSS

JavaScript

🎮 How to Play

Open the game in your browser.

Choose Stone, Paper, or Scissor.

The computer randomly chooses one of the three options.

The game determines the winner based on the rules of Stone Paper Scissor.
